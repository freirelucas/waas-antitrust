## Autoria

O projeto é mantido por **L.** (forma como o autor optou por se identificar publicamente nesta fase do trabalho). O repositório de código é
[github.com/freirelucas/waas-antitrust](https://github.com/freirelucas/waas-antitrust);
o contato preferencial para discussão pública é a abertura de uma
[issue no GitHub](https://github.com/freirelucas/waas-antitrust/issues).

### Vinculação institucional

**Pesquisador independente.** O autor mantém este repositório
**sem vinculação institucional formal** ao CADE, ao IPEA, a escritório
de advocacia ou a empresa privada. Versões anteriores dos metadados
([`CITATION.cff`](https://github.com/freirelucas/waas-antitrust/blob/main/CITATION.cff)
e [`.zenodo.json`](https://github.com/freirelucas/waas-antitrust/blob/main/.zenodo.json))
declaravam vinculação a programa institucional do IPEA; a partir da
versão `0.2.0-draft` (jun/2026) essa atribuição foi removida — o
trabalho é mantido de forma independente.

Eventual menção a colaboração futura com instituições aparecerá no
[`CHANGELOG.md`](https://github.com/freirelucas/waas-antitrust/blob/main/CHANGELOG.md)
e neste documento; até lá, não há.

## Como citar

A forma canônica de citação está em
[`CITATION.cff`](https://github.com/freirelucas/waas-antitrust/blob/main/CITATION.cff)
(formato Citation File Format 1.2; o GitHub renderiza o widget "Cite this repository" automaticamente na página do repositório).

Em texto corrido, sugestão para a versão atual:

> L. (2026). *LCMC — Leniência Condicionada à Massa Crítica: canal de
> depósito condicional para condutas unilaterais em mercados digitais.*
> Software v0.2.0-draft. <https://freirelucas.github.io/waas-antitrust/>

Em BibTeX:

```bibtex
@misc{lcmc2026,
  title  = {{LCMC} -- {L}eni{\^e}ncia {C}ondicionada {\`a} {M}assa {C}r{\'i}tica:
            canal de dep{\'o}sito condicional para condutas unilaterais em
            mercados digitais},
  author = {L.},
  year   = {2026},
  note   = {Software v0.2.0-draft},
  url    = {https://freirelucas.github.io/waas-antitrust/},
}
```

## Contato

- **Discussão pública:** [issues no GitHub](https://github.com/freirelucas/waas-antitrust/issues) — preferido para questões técnicas, sugestões e crítica formal.
- **Imprensa, autoridades, eventos:** abrir issue marcada com `kind: imprensa` ou `kind: autoridade`. O autor responde via comentário público para preservar a transparência do processo.

A política do projeto é manter o máximo de discussão substantiva em
canal aberto e auditável.
